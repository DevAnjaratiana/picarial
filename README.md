# Picarial Agency — Site vitrine

> Site vitrine responsive d'une agence digitale, réalisé en HTML5 / Sass (SCSS).

![Aperçu du site](./assets/images/preview.png)

---

## 📖 Description

**Picarial Agency** est un site vitrine moderne conçu pour une agence digitale fictive.  
Il présente les services, les témoignages clients et les informations de contact dans une interface élégante et responsive.

Projet réalisé dans le cadre de la **Licence 3 Informatique de Gestion** (IS-INFO).

---

## 🚀 Technologies utilisées

| Catégorie | Technologies |
|---|---|
| **Frontend** | HTML5 sémantique |
| **Styles** | Sass (SCSS) — architecture 7-1 |
| **CSS avancé** | Flexbox, CSS Grid, variables, mixins |
| **JavaScript** | Vanilla JS (menu burger) |
| **Outils** | npm, Sass CLI, VS Code, Git/GitHub |

---

## ✨ Fonctionnalités

- 🎨 Design moderne et épuré (fidèle à la maquette Figma)
- 📱 **Responsive** — mobile, tablette, desktop
- 🍔 **Menu burger** en version mobile
- 🎯 Liens actifs avec **soulignement doré**
- 🔍 Barre de recherche (icône)
- 🌐 Sélecteur de langue (FR / EN)
- 📊 Statistiques animées (section À propos)
- 💬 Cartes de témoignages clients
- 🎯 CTA (Call to Action) avec fond sombre
- 📄 Footer complet avec navigation et contact
